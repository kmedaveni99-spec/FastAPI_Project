# 📸 Snapogram – Social Media App (FastAPI + Streamlit)

Snapogram is a **full-stack social media application** where **authenticated users** can upload images/videos and view a shared feed.  
The backend is built with **FastAPI**, **JWT authentication**, **SQLAlchemy ORM**, and **ImageKit.io**, while the frontend is developed using **Streamlit**.

This project demonstrates **real-world backend development**, secure authentication, async database operations, and frontend–backend integration.

---

## ✨ Features

- 🔐 JWT-based authentication (Login / Register)
- 👤 User authorization using FastAPI Users
- 📤 Upload images & videos
- ☁️ Cloud media storage using ImageKit.io
- 📰 Feed displaying posts from all users
- 🗑 Delete posts (only by owner)
- 🗄 SQLite database with SQLAlchemy (Async)
- 🖥 Streamlit frontend
- 📄 Auto-generated API docs (Swagger UI)
